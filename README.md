# Document Extractor

A Python-based document processing system that uses AI to extract structured information from documents, validate extracted fields, and identify information requiring human review.

## Overview

Document Extractor is a research prototype designed to improve the accuracy and efficiency of processing unstructured documents.

The system combines AI-powered information extraction with rule-based validation to identify missing, invalid, or uncertain information.

The current implementation focuses on personal-injury intake forms and serves as a foundation for researching document extraction and validation techniques.

## Features

- **AI-Powered Extraction:** Uses Anthropic Claude to extract structured information from document images.
- **PDF and Image Support:** Processes PDF, PNG, and JPEG files.
- **Structured Data:** Extracts 13 predefined fields into a consistent format.
- **Field Validation:** Checks required information, formatting, dates, and selected field relationships.
- **Confidence-Based Review:** Flags fields with low model-reported confidence or validation issues.
- **Command-Line Interface:** Displays extraction results and validation findings.
- **Offline Testing:** Supports reproducible demonstrations using predefined fixtures.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/EthanTH04/Document-Extraction.git
cd Document-Extraction
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate the environment:

**Windows (Git Bash):**
```bash
source .venv/Scripts/activate
```

**macOS/Linux:**
```bash
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

## Usage

### Run an offline demonstration

```bash
python run.py samples/03_messy.png --fixture
```

This uses a predefined fixture instead of making an API request.

### Run live AI extraction

Set the `ANTHROPIC_API_KEY` environment variable, then run:

```bash
python run.py samples/01_clean.png
```

Live extraction requires API access and may incur usage charges.

### Run automated tests

```bash
python -m pytest -q
```

## Testing and Evaluation

The initial prototype includes 18 passing automated validation tests in the previously reviewed repository snapshot.

The tests evaluate deterministic validation behavior, including required fields, formatting, and consistency checks.

**Current limitations:**

- Live AI extraction has not been independently evaluated end to end.
- Extraction accuracy has not yet been measured.
- Offline test fixtures are manually prepared rather than generated by the AI model.
- The extraction schema currently targets one document category.
- Model-reported confidence scores have not been calibrated.

These limitations will inform subsequent implementation and evaluation.
