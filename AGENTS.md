# Instructions for coding agents

- Work only on the current branch. Never commit to main.
- After each change that leaves the tests passing (python -m pytest -q), make a commit.
- One commit per change. Do not batch unrelated edits.
- Write the commit message yourself: what changed, then why, in the imperative.
- Ask me for the Checked: lines before committing. Do not invent them.
- Do not merge until I say the branch is reviewed and finished.
- When I do, merge into main with --no-ff, push, and delete the branch.
- Never write an API key into any file. Keys come from the environment only.
- Do not edit files in samples/ to make a test pass. Fix the code or ask me.
